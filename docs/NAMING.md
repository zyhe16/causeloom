# Naming

- **Display name:** Causeloom
- **Skill ID:** `causeloom`

The name and slogan describe the skill's two-part method. It traces the causal
structure of a software problem, then weaves requirements, repository evidence,
implementation, and verification into a solution that holds together.

Use **Causeloom** in prose and `causeloom` for directories, packages, commands,
condition identifiers, and repository paths.
