# Security policy

Causeloom is instruction-only, but its guidance can still influence code
changes, tool use, and trust-boundary decisions.

Please report security problems through GitHub's private vulnerability-reporting feature once the repository is published. Relevant reports include instructions that systematically weaken authentication, authorization, data integrity, migration safety, secret handling, sandboxing, or verification.

Do not include real credentials, private repositories, or sensitive benchmark data in a public report.

Supported version: `0.3.x` and the latest release on the default branch.
